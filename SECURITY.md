# Security policy

VEIL Player Mobile is currently a pre-release source candidate. Supported security
updates are tracked on the current development line; no response or release
timeline is promised.

Please report suspected vulnerabilities privately where possible. The
preferred future route is GitHub private vulnerability reporting after it is
enabled for the public repository. Until then, contact:

**Allam Zedan — allamzedan@live.com**

Do not publicly disclose an exploitable issue before reasonable coordination.
Include affected versions, reproduction steps, impact, and any suggested
mitigation. Do not send real credentials, private media, or unnecessary
personal data.
